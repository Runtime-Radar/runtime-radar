# Chart

## Parameters

### Global parameters

| Name                                   | Description                                                                                 | Value |
| -------------------------------------- | ------------------------------------------------------------------------------------------- | ----- |
| `global.imageRegistry`                 | Global Docker image registry                                                                | `""`  |

| `global.prometheus.tls.certCA`         | CA Certificate value. Requires `tls.autoGenerated` to be `false` (overrides `tls.certCA`)   | `""`  |
