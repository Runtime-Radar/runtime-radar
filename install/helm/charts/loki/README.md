# Chart

## Parameters

### Global parameters

| Name                             | Description                                                                                 | Value |
| -------------------------------- | ------------------------------------------------------------------------------------------- | ----- |
| `global.imageRegistry`           | Global Docker image registry                                                                | `""`  |
| `global.imagePullSecrets`        | Global Docker registry secret names as an array                                             | `[]`  |
| `global.storageClass`            | Global StorageClass for Persistent Volume(s)                                                | `""`  |
| `global.loki.tls.enabled`        | Enable TLS traffic support (overrides `tls.enabled`)                                        | `nil` |
| `global.loki.tls.autoGenerated`  | Generate automatically self-signed TLS certificates (overrides `tls.autoGenerated`)         | `nil` |
| `global.loki.tls.existingSecret` | Name of an existing secret that contains the certificates (overrides `tls.existingSecret`)  | `""`  |
| `global.loki.tls.cert`           | Certificate value. Requires `tls.autoGenerated` to be `false` (overrides `tls.cert`)        | `""`  |
| `global.loki.tls.certKey`        | Certificate key value. Requires `tls.autoGenerated` to be `false` (overrides `tls.certKey`) | `""`  |
| `global.loki.tls.certCA`         | CA Certificate value. Requires `tls.autoGenerated` to be `false` (overrides `tls.certCA`)   | `""`  |
